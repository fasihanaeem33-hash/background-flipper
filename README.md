# Background Flipper

A small frontend project that changes the page background color when the user clicks the button.

## Files

- `index.html` — main page layout and styling
- `app.js` — JavaScript logic for changing the background color and displaying the color name

## How to use

1. Open `index.html` in a web browser.
2. Click the **Change Background Color** button.
3. The background color will update randomly and the displayed color name will change.

## Notes

- The project uses a fixed array of colors defined in `app.js`.
- This is a simple demo suitable for learning basic DOM manipulation and event handling.
